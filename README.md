## 🧮 Formulasi Matematika Finansial &amp; Evaluasi Risiko

Seluruh landasan matematis komputasi bunga majemuk anuitas, simulasi akumulasi Dollar Cost Averaging, cicilan amortisasi pinjaman, serta rasio imbal hasil terhadap volatilitas risiko (Sharpe Ratio) disajikan dalam kartu vektor beresolusi tinggi berikut:

<p align="center">
  <img src="assets/financial_formulas.svg" width="100%" alt="Quantitative Financial Formulations" style="border-radius: 12px; border: 1px solid #1e293b; box-shadow: 0 8px 24px rgba(0, 0, 0, 0.4);" />
</p>

### Ringkasan Tahapan Komputasi &amp; Formula Finansial

| Komponen Finansial | Formulasi Matematis Utama | Variabel Operasional | Peran dalam Sistem |
|---|---|---|---|
| **1. Bunga Majemuk Anuitas** | FV = P (1 + r/n)^(nt) + PMT · [ ((1 + r/n)^(nt) − 1) / (r/n) ] | P: Modal Awal, r: Bunga Tahunan, n: 12 Bulan, t: Tahun, PMT: Setoran Bulanan | Menghitung proyeksi pertumbuhan modal investasi jangka panjang |
| **2. Akumulasi Investasi DCA** | V_t = Σ D_k · Π (1 + r_j) | D_k: Investasi Rutin Bulanan, r_j: Estimasi Return Bulanan, t: Durasi Bulan | Menghitung akumulasi nilai portofolio dengan mitigasi volatilitas |
| **3. Net Trading Profit/Loss** | Net_PL = Total_Jual − Total_Beli − Fee_Transaksi | Harga_Beli, Harga_Jual, Kuantitas Unit, Persentase Biaya Transaksi | Evaluasi imbal hasil trading bersih setelah potongan biaya broker |
| **4. Cicilan Anuitas Pinjaman** | M = P · [ (r (1 + r)^n) / ((1 + r)^n − 1) ] | P: Pokok Pinjaman, r: Bunga per Periode, n: Total Tenor Cicilan | Menghitung angsuran bulanan tetap dengan amortisasi pokok menurun |
| **5. Imbal Hasil Portofolio** | R_p = Σ (w_i · R_i) dengan Σ w_i = 1.0 | w_i: Bobot Valuasi Aset i, R_i: Imbal Hasil Historis Aset i | Menghitung tingkat pengembalian modal gabungan multi-kripto |
| **6. Sharpe Ratio (Risk-Adjusted)** | Sharpe = (R_p − R_f) / σ_p | R_p: Return Portofolio, R_f: Suku Bunga Bebas Risiko, σ_p: Volatilitas | Mengukur apakah keuntungan portofolio sebanding dengan risiko |

### 🌐 Akses Langsung via Web (Cloud Demo)

👉 **[https://finance-guru-ai.streamlit.app](https://finance-guru-ai.streamlit.app)**

---

### 💻 Instalasi &amp; Eksekusi Mandiri di Komputer Lokal

#### 1. Prasyarat Sistem
- **Python**: `v3.10.x`, `v3.11.x`, atau `v3.12.x`
- **Kunci API Groq**: Dapatkan API Key gratis di [console.groq.com](https://console.groq.com)

#### 2. Kloning Repositori &amp; Penyiapan Virtual Environment
```bash
# 1. Kloning repositori
git clone https://github.com/HyLuthfi/finance-guru-ai.git
cd finance-guru-ai

# 2. Buat dan aktifkan virtual environment
python -m venv .venv
# Windows (Git Bash):
source .venv/Scripts/activate
# Linux / macOS:
# source .venv/bin/activate

# 3. Pasang seluruh dependensi pustaka
pip install -r requirements.txt
```

#### 3. Konfigurasi Kunci API (Pilih Salah Satu Jalur)
- **Opsi A (Via `.env` file):**
  ```bash
  cp .env.example .env
  # Isi GROQ_API_KEY=gsk_... pada berkas .env
  ```
- **Opsi B (Via Streamlit Secrets):**
  ```bash
  cp .streamlit/secrets.toml.example .streamlit/secrets.toml
  # Isi GROQ_API_KEY = "gsk_..." pada berkas .streamlit/secrets.toml
  ```
- **Opsi C (Via Antarmuka Web Langsung):**
  Anda dapat memasukkan API Key secara langsung pada kolom input sandi di sidebar aplikasi saat peramban terbuka.

#### 4. Menjalankan Dashboard Streamlit
```bash
streamlit run app.py
```
Aplikasi web analitik akan secara otomatis terbuka di peramban Anda pada tautan lokal `http://localhost:8501`.
